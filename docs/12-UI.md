# UI aplikacji

Interfejs ma działać czytelnie w biurze, hali, magazynie i terenie. Aktywny workspace jest zawsze widoczny.

## Wzorce

- listy: wyszukiwanie, filtry, sortowanie i paginacja;
- szczegóły: stan, kluczowe dane, relacje i dozwolone akcje;
- formularze: etykiety, wymagane pola, walidacja przy polu i podsumowanie;
- każdy ekran: loading, pusty stan, błąd, brak uprawnień i sukces;
- operacje destrukcyjne jasno opisują skutek.

## Dostępność i urządzenia

Cel to WCAG 2.2 AA, obsługa klawiaturą, widoczny fokus, semantyczne kontrolki, odpowiedni kontrast i cele dotykowe minimum 44 × 44 px. Web ma być responsywny; mobilnie priorytetem są QR, zadania i zgłoszenia.

Pierwszym językiem jest polski. Kolejne języki są do decyzji.
