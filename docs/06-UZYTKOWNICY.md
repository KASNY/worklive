# Użytkownicy i pracownicy

## Rozróżnienie

**Użytkownik** jest globalnym kontem logowania. **Pracownik** jest rekordem biznesowym w konkretnym workspace. Rekord pracownika może zostać połączony z kontem.

## Zapraszanie

1. Właściciel lub administrator podaje adres e-mail i rolę.
2. System tworzy jednorazowe, czasowe zaproszenie dla workspace.
3. Odbiorca loguje się albo tworzy konto i akceptuje zaproszenie.
4. Powstaje aktywne członkostwo; operacja trafia do audytu.

Token zaproszenia jest przechowywany wyłącznie w postaci skrótu. Musi być możliwe unieważnienie i ponowienie zaproszenia. Dokładny czas ważności i dostawca e-mail są do decyzji.

Dezaktywacja członkostwa odbiera dostęp do workspace bez usuwania historii autora operacji.
