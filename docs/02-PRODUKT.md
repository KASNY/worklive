# Produkt

## Odbiorcy

- firmy produkcyjne zarządzające maszynami, lokalizacjami i pracą;
- firmy serwisowe obsługujące zasoby i zgłoszenia;
- firmy magazynowe potrzebujące ewidencji i szybkiego dostępu do danych.

## Platformy

- marketingowa strona webowa;
- przeglądarkowy workspace firmy;
- backend API;
- aplikacja mobilna do QR, zadań i zgłoszeń;
- aplikacja desktopowa dla Windows, macOS i Linux.

## Wartość

Użytkownik otrzymuje jeden kontekst firmy, kontrolowany dostęp, powiązane dane i historię pracy. Szczegółowy zakres określa `04-MODULY.md`.

## Granica

Funkcja niewymieniona w dokumentacji nie jest częścią produktu. Nowa funkcja wymaga najpierw aktualizacji dokumentów, danych, uprawnień i roadmapy.
